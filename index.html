Experience Digit Recognition from the Neural Network Perspective

A small convolutional network, 99% accurate on MNIST, running live in your browser. Weights: ONNX Model Zoo (MIT).

What is a neural network?

A neural network is a program that learns from examples instead of following rules someone wrote by hand. It is built from layers of simple units. Each unit takes in numbers, weighs them and passes a result on. Training adjusts those weights over thousands of examples until the answers come out right. The network on this page was trained in advance; nothing is learned while you draw.

How does it read a digit?

It learned from MNIST: 70,000 handwritten digits, each a 28 × 28 grid of grey pixels. So your drawing is first centred and shrunk to that grid, shown as Network sees. Those 784 pixels go in at the bottom of the demo, and ten numbers come out at the top, one for each digit from 0 to 9. The biggest one is the answer; its size is the network's confidence.

What makes it a convolutional network (CNN)?

A plain network treats every pixel separately. A CNN uses small filters that slide over the whole image, looking for the same pattern everywhere.

  • Layer 1 has 8 filters, each a 5 × 5 patch: green wants ink, magenta wants empty paper. Each filter makes a map of where its stroke shows up in your drawing: an edge, a line at some angle, a curve.
  • Layer 2 has 16 filters that work on layer 1's maps, so they find combinations of strokes: a loop, a corner, a crossing.
  • Between layers the maps are shrunk, keeping the strongest signal in each small area, so each layer sees a bigger part of the digit.
  • At the top, all 16 maps are combined into the ten outputs.

Click any filter or map in the demo to see it larger. One limit: the network only knows digits. Draw a letter or a face, and it will still pick a digit.
